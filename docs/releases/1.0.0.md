# RunFlow 1.0.0 — Training, activities, and progress

First curated stable release of the native Android app under the new 1.0.0 release series.

- Plan training and follow guided workouts with offline support.
- Review activities and training analytics, with optional self-hosted account synchronization.
- Use Health Connect integration and the shared training-plan engine.
- Signed APK and AAB downloads include verified package metadata and SHA-256 checksums.

The displayed version restarts at 1.0.0; the Android version code increases so current native installations can update. Uncommitted local development changes are not included.

Download the APK to install. The AAB is for future store distribution. Existing native releases signed with certificate `539151c5b2faa7d68bde4266a9277a7bd4fda76b091d53998a89585ab85d2094` update normally. Older GitHub APKs signed with a different key require backing up data and reinstalling.
