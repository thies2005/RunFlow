RunFlow web — redesign proposals

Three directions for replacing the current glassmorphism look. Each direction is a full dashboard mockup using real RunFlow content (this week's plan, race countdown, CTL/ATL/TSB, readiness, activity log), followed by a login variant. All three share the same rules: no gradients, no glow, no glass, borders instead of shadows, sentence-case labels, and motion only on state change.

Why the current UI reads as vibe-coded

Taken from globals.css and the dashboard markup — these are the tells to eliminate, regardless of which direction is chosen:

  • Orange→pink→purple gradient (#ff6b35 → #f72585 → #7209b7) on buttons, badges, avatars, borders
  • Gradient-clipped text on stat values (background-clip on .stat-value)
  • Glassmorphism: backdrop-blur cards, translucent borders, .glass-card everywhere
  • Glow shadows (.glow-orange/.glow-pink, 0 8px 25px rgba pink) around interactive elements
  • translateY(-2px) hover bounce on every button
  • Infinite pulse/glow/slide-up animations on non-interactive content
  • Inter — the default font — with font-black + tracking-tighter vs tracking-widest mixed
  • Uppercase tracked-out labels on every metric (uppercase tracking-widest font-bold)
  • ~15 accent colors in play at once (orange, pink, purple, cyan + 7 workout + 5 zone colors)
  • One 16px border-radius on everything regardless of hierarchy
Direction A

Race Timing

RunFlow's numbers come from timing: paces in seconds per kilometre, CTL in daily load, a race in days. This direction treats the app as a timing board — flat signal orange, tabular monospace digits at scoreboard scale, a dark instrument rail for navigation, and white panels divided by 1px rules instead of shadows. The one bold element is the black stat board; everything around it stays quiet.

Paper #F6F7F5 Ink #16181A Signal #E8501A Green #2E7D5B Red #C0392F
Type — Archivo (UI) / IBM Plex Mono (data) Radius — 6px panels, 3px tags Elevation — none; 1px borders
What changes from today:
  • Gradients and glow replaced by one flat signal orange, reserved for three jobs only: today's session, primary actions, and the critical series. Green and red carry delta direction; nothing else gets color.
  • The training-status card is promoted to a full-width scoreboard — the first thing you see is your numbers, set in tabular mono like a clock. Words stay in the grotesque, numerals in mono.
  • Navigation moves to a dark left rail, which gives the content area a calm paper field instead of a sticky glass bar.

    Direction B

    Head Unit

    Most RunFlow sessions start before sunrise, next to a watch. This direction borrows the grammar of a GPS head unit: matte charcoal panels, data fields as bordered cells with big monospace readouts, status lamps instead of badges, and a single sodium-amber accent for "now". Readability in the dark is the design argument; the watch strip across the top is the one bold element.

    Predawn #101312 Panel #171B1A Amber #FFB000 Teal #3FBF9F FG #E8ECE9
    Type — Space Grotesk (UI) / IBM Plex Mono (data) Radius — 10px fields Elevation — none; 1px #2A302D borders
    What changes from today:
  • Dark mode without glass: opaque matte panels, no backdrop-blur, no glow — contrast comes from the digits, not from light effects.
  • Color has strict semantics: amber marks now (today's cell, active marker, primary action), teal marks positive physiology (VO₂max gain, completed sessions); Strava orange appears only on Strava's own button.
  • Readiness is promoted to a watch-style field strip (score, RHR, HRV, sleep, weekly load) — one glance answers "how am I today".
  • Completed sessions are dimmed rather than decorated — completion is the default state, not an achievement.

    Direction C

    Lab Report

    RunFlow's health data — RHR, HRV, sleep, readiness — is physiology, and physiology has a native visual language: the millimetre grid of ECG paper and the ruled tables of a lab report. This direction sets the app as a periodic report: a serif "chart note" voice, italic field labels, ruled tables with day-gutters, and one clinical red used for the trace and for "today". The ECG-grid chart panel is the one bold element.

    Paper #FBFAF7 Ink #1A1B1E Clinical red #C0392F Green #2E7D5B ECG grid pink
    Type — Source Serif 4 (prose/labels) / IBM Plex Mono (data) Radius — 0 Elevation — none; ruled lines only
    What changes from today:
  • Zeros in on the analytical promise: the page reads as a document you consult, not a feed you scroll — full-width ruled sections instead of a card mosaic.
  • The ECG millimetre grid is used only where it means something (physiology charts); it is texture with an axis, not decoration.
  • Race day, form values and race predictions sit in a fixed right margin like a report's reference block.
